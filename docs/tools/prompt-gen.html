💡 这个工具的设计思路

  • 场景 × 角色 × 格式 × 风格 四个维度拼接，避免每次从零写 prompt
  • 自检 checklist 帮你判断 AI 回答质量（不是单看"它说了什么"，而是"它有没有做到"）
  • 反例提醒 提前告诉你这个 prompt 容易写错的几种方式
  • 占位符提示：模板里有 {CODE} 这种占位符，告诉你该填什么

⚠️ 生成的 prompt 是起点不是终点。真要用时还是要根据实际情况微调，但 80% 情况直接复制能用。
