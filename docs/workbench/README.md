# 内容工厂工作台

## 使用方式

直接在浏览器打开 `index.html` 即可使用，所有数据保存在浏览器 localStorage。

### 核心功能

1. **热点看板**：浏览、筛选、导入热点数据
2. **选题管理**：从热点中选出值得写的题材
3. **改写工作台**：对选中的热点进行改写，支持多平台分发
4. **发布记录**：跟踪各平台的发布状态
5. **内容库**：查看历史内容，支持全量备份/恢复
6. **系统设置**：管理分类、标签、平台配置

### 数据迁移

- **导出**：热点/选题/发布记录支持 JSON 导出
- **备份恢复**：系统设置中有"全量备份"和"恢复备份"按钮
- **跨终端**：将备份 JSON 文件复制到新电脑，在系统设置中恢复即可
